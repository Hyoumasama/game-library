# The Game Awards historical verification — 2026-10-08

Branch: `feature/game-awards`. All twelve ceremony files and the unapplied seed are published and verified. No production database writes, deployment, or merge.

Nomination counts include winners and honorary recipient groups. “Matched” and “unresolved” count game-associated award entries, including performance credits; they are not unique-game counts. Unresolved library links are not missing historical results. Unowned and unlinked nominees remain visible by default; only the optional ownership filter hides them.

Full nominee identities, winner flags, library IDs, ownership, source nominee labels, category evidence, and unresolved entries are in [the machine-readable report](../data/awards/verification/report.json). Source URLs and response fingerprints are in [sources.json](../data/awards/verification/sources.json). Reviewed changes are in [corrections.json](../data/awards/verification/corrections.json). Cached official rewind records were prioritized; contemporary specialist reporting supplied complete nominee lists and corrections to erroneous archive labels. Primary recipient statements and organizer videos supplemented honorary records.

## Application verification

The isolated PGlite database imports all 1,773 entries, matches 734 game-associated awards, retains all 2,348 inventory rows, and agrees with the JavaScript matcher. Publication through the authenticated route commits the event first and immediately expires awards, library, browsing, and Stats caches. A localhost browser test warms the staged caches, rejects the wrong database and an unverified year, publishes 2025 locally, and checks all four surfaces on the next request. Owned awards won increase from 146 to 163. See [publication test](awards-publication-report.json) and [responsive browser checks](awards-browser-fixture-report.json). These tests never use production Supabase.
